# Data Directive — HomeMatch

## Home Listings CSV
- File: `data/home.csv`
- Columns: `Neighborhood, Location, Bedrooms, Bathrooms, House Size (sqft), Price (k$)`
- Source: Generated by LLM (`HomeMatch.ipynb`) or provided manually.
- The file is gitignored (generated data). Regenerate via the notebook or `HomeMatch.py`.

## Vector Store
- Engine: ChromaDB
- Persist directory: `db/` (gitignored — rebuilt on each run if missing).
- Embedding model: `text-embedding-ada-002` via `OpenAIEmbeddings`.

## Constraints
- CSV must exist at `settings.data_path` before running recommendation engine.
- If CSV is missing, run the data generation step in `HomeMatch.ipynb` first.
